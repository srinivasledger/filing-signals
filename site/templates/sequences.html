Sequences

Companies with signals from more than one filing occasion. Each timeline shows their order and elapsed time, using filing dates.

These records show what was disclosed and when. One event does not imply that another will follow.

What is not a sequence. A Form 12b-25 followed by the report it deferred is Rule 12b-25 working, not a company deteriorating: the rule grants five calendar days for a 10-Q and fifteen for a 10-K, and the disclosure the tracker then reports comes from that very report. Those pairs are excluded, as are two signals read out of a single filing. One filing is one occasion.

The rule, exactly. A company counts once, not once per event. For each pair, the denominator includes companies whose earliest observed first event was at least {{ history.window_days }} days before the date above. A follow-on counts if the second event appears strictly after that first event and within {{ history.window_days }} days of it. Same-day pairs are excluded. Companies still within the window are excluded even if a second event has already appeared.

Records include the recent submissions index and every older file it lists. The observation period starts on {{ history.observation_start }}, when the current 8-K item numbering took effect; earlier late notices are excluded because their follow-on events were not reported under the same item codes. EDGAR coverage and item coding vary across issuers, so the earliest observed event may not be the first in a company’s life. The window measures elapsed calendar time; a company that stops SEC reporting can leave later events unobserved.
